# CK Quant 2026.8.6

## 修复：服务器管理配置金额保存

- 修复 WebUI 与 Android APK 修改 `stake_amount` 后保存失败的问题。
- 数字字符串（例如 `"3"`、`"2.5"`）会在提交前转换为合法 JSON 数值。
- 服务器管理 API 同时兼容旧版 APK 发送的数字字符串，因此更新服务器镜像后旧 APK 也可以继续使用。
- `"unlimited"` 保持原有语义，不会被错误转换。
- 无效文本仍交由服务器正常校验并返回明确错误。

## 安全与兼容性

- 前端和服务器端执行双层规范化，覆盖快速设置、高级编辑器及旧客户端。
- 保存前仍执行完整的 Freqtrade 配置一致性校验。
- 原有自动备份、审计日志、配置冲突检测和失败自动回滚机制保持不变。
- 基于 2026.8.5 的交易对筛选、实时 ROI 仪表盘及手机端 UI 改进继续保留。

## 验证

- 前端格式、ESLint 与 TypeScript 类型检查通过。
- 前端 7 项相关单元测试通过。
- 后端管理 API 7 项测试通过。
- 本地 Docker 模拟盘验证通过。
- 两台独立实盘服务器已验证字符串金额配置有效，容器运行且重启次数为 0。
