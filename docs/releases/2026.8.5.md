# CK Quant 2026.8.5

## 🚀 新功能：交易对白名单管理器（服务器管理）

在 WebUI 的「服务器管理」页面新增**交易对列表展示与自选添加**功能：

- 加载币安全部 **678 个 USDT 永续交易对**
- 默认按 24 小时成交额从高到低排列
- 支持按 **涨幅 / 跌幅** 排序和**交易对搜索**
- 列表固定高度（约 20 行），滚轮浏览全部交易对
- **勾选**交易对即可加入白名单草稿；右侧**取消勾选**即删除
- 正则白名单会显示提示，避免与逐个选择混淆
- 支持现有**七种界面语言**；手机端自动变成上下布局

### 安全机制

- 勾选操作**只修改页面草稿**，不会立即改写配置或重启机器人
- 确认选择后点击「仅保存」或「保存并重启机器人」才生效
