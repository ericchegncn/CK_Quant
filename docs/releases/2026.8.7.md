# CK Quant 2026.8.7

## 综合权益回撤

- WebUI 首屏和 Telegram `/profit` 统一按综合权益计算回撤，包含已平仓收益与当前未平仓浮动盈亏。
- “最大回撤”保存机器人生命周期内的历史峰谷最大纪录；行情恢复后不会下降，只有出现更大回撤时才更新。
- “当前回撤”根据最新综合权益实时变化，权益恢复到历史新高时回到零。
- 最大回撤状态持久化到交易数据库，容器重启后继续保留。
- 回撤区间起止金额通过 API 完整返回，不再显示为 `N/A`。

## 仪表盘体验

- “全部交易收益率”调整到左侧，“已平仓交易收益率”调整到右侧。
- 收益率与指标小卡片增加悬停边框高亮、背景和阴影过渡。
- WebUI 与 Android APK 使用相同的响应式仪表盘。

## 验证

- 回撤核心、API 与 Telegram `/profit` 测试通过。
- 已验证最大回撤只增不减，而当前回撤会随综合权益动态变化。
- TypeScript 类型检查、ESLint 和前端生产构建通过。
- 两个独立 Docker 模拟盘已验证，容器运行且重启次数为零。
- 隐私保护继续生效：真实策略、配置、数据库、凭据和服务器信息不进入 Git、APK 或官方 Docker 镜像。
