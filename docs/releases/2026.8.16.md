# CK Quant 2026.8.16

## 仪表盘利润曲线修复

- 修复交易历史超过 WebUI 缓存上限后，累计利润曲线只统计最近一页订单的问题。
- 新增轻量级完整利润历史接口，只返回平仓时间和累计利润，不加载订单明细。
- 已平仓利润曲线末端现在与“已平仓交易收益率”一致。
- 虚线从已平仓累计利润延伸到“已平仓利润 + 当前未平仓浮动利润”，与“全部交易收益率”一致。
- 未平仓利润投影刷新间隔缩短至 5 秒，减少高波动行情中的显示差异。
