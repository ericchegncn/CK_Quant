# CK Quant 2026.8.1

这是 CK Quant 2026.8 的界面修复版本。

## 修复

- 语言选择菜单现在始终使用各语言的原生名称：`简体中文`、`繁體中文`、
  `English`、`Deutsch`、`日本語`、`Français`、`한국어`。
- 修复中文界面中其他语言名称被翻译成“英语、德语、日语”等，导致国际用户
  难以识别目标语言的问题。

## Android APK

本 Release 附带 `CK-Quant-Android-0.1.1-debug.apk`，继续使用 CK Quant 品牌
图标，供移动管理功能测试。

SHA-256：`C93B0F96731F91099CC8ABDAC6EFFEC6CACF6A9B7B6276ECECD02448F5BAE3E0`

管理功能需要在服务器实际加载的 `config.json` 顶层显式启用：

```json
"ck_quant_admin": {
  "enabled": true,
  "config_edit": true,
  "strategy_edit": true
}
```

修改后重启 CK Quant 容器。远程访问请使用 HTTPS 反向代理或可信 VPN，切勿将
管理端口直接暴露到公网。
