# CK Quant 2026.8.15

## 交易对白名单修复

- WebUI“交易”页面现在只显示 PairListManager 最终生成的交易对白名单。
- 混合 `union` 模式继续按成交额榜、涨幅榜和跌幅榜生成并集，重合交易对自动去重。
- 为保证未平仓订单持续获得行情数据而追加的内部交易对，不再混入 WebUI、REST 或 WebSocket 白名单。
- Telegram `/whitelist` 改用最终生成的白名单，并在内容超过 Telegram 长度限制时自动分段发送。

- FreqAI 与 FreqAI-RL 镜像暂不更新。
