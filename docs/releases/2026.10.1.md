# CK Quant 2026.10.1

WebUI 新增一键「全部平仓」按钮（桌面端 + 手机端），配套 Android 调试包，并把说明文档补齐为 7 种语言。

## 背景

希望不进 Telegram、也不逐笔点单，就能在 WebUI 里一次平掉当前关注的全部持仓。

后端其实**早已支持**：`POST /forceexit` 传 `tradeid="all"` 时，`_rpc_force_exit` 会展开为
「所有未平仓逐笔平仓」；Telegram 的 `/forceexit all` 走的是同一条路径。缺的只是界面入口。

## 界面入口

- **位置**：持仓表格/列表**上方右侧**（桌面端 `TradeList.vue`、手机端 `MobileTradesList.vue`），
  无持仓时自动隐藏。
- **标签带数量**（如「全部平仓 (31)」），一眼看清这一下会影响多少笔。
- **作用范围 = 该列表里实际展示的那些 bot**：多 bot 合并视图下平掉全部被展示的 bot，
  避免出现「界面显示 33 笔、按钮却只平掉当前 bot 的 12 笔」这类更危险的错配。
- 刻意**不做浮动按钮、也不放导航栏**：卡片标题栏本身是拖拽手柄（会抢点击事件），
  而浮动按钮在手机上最易误触，且会遮挡表格右侧的盈亏列。

## 安全设计

- **刻意不受「跳过确认弹窗」设置影响** —— 不可逆的批量操作必须二次确认。
- 目标里**含实盘 bot 时追加第二次确认**，弹窗文案明确写出"包含实盘"。
- 后端零改动、复用既有接口；单笔平仓 / 删除交易 / 取消挂单等既有动作完全不变。

## 多语言

- 界面新增 4 条文案，覆盖项目既有的 7 种语言（`zh-CN`、`zh-TW`、`en`、`de`、`fr`、`ja`、`ko`）：
  按钮名、提示、确认正文、实盘二次确认正文。
- 说明文档同步补齐为 7 种语言：`README.md`（英）、`README.zh-CN.md`、`README.zh-TW.md`、
  `README.de.md`、`README.fr.md`、`README.ja.md`、`README.ko.md`，各文件顶部语言切换行互相链接。

## 镜像

本版镜像（含本次界面改动，也含 2026.9.4 的全部主循环提速）：

```bash
docker pull ericchenghz/ck-quant:2026.10.14-closeall   # 基础镜像（本次发布）
docker pull ericchenghz/ck-quant:latest                # 指针，与上面同 digest
docker pull ericchenghz/ck-quant:stable                # 指针，与上面同 digest
docker pull ericchenghz/ck-quant:2026.10.14-closeall-freqai
docker pull ericchenghz/ck-quant:freqai                # 指针
```

`freqai-rl` 族的指针同步安排在下一次镜像发布。

## 移动端

Android 调试包 **0.1.16**（`versionCode 17`）随本版发布，内含该按钮；校验值见发布附件中的 `.sha256`。

## 验收口径

- 刷新 WebUI：持仓列表上方出现「全部平仓 (N)」，N 与列表里的未平仓数一致。
- 无持仓时按钮消失；点开确认框会写明将影响的数量；目标是实盘 bot 时会出现第二次确认。

## 隐私保护

发布源码与全部 Docker 镜像均不包含私有策略、实盘配置、API 密钥、Telegram Token、服务器 IP、
数据库、回测结果或模型数据。
