# CK Quant 2026.9.3

Telegram 机器人消息多语言（**后端与文案改动，前端未改，本版沿用现有 APK**）。

## 新功能：机器人消息多语言（与 WebUI 相同的 7 种语言）

- **覆盖范围**：开仓/加仓、平仓/部分平仓、强平告警、保护位触发、订单取消等通知；以及
  `/status`（含 `table`）、`/profit`、`/balance`、`/daily`、`/weekly`、`/monthly`、
  `/performance`、`/entries`、`/exits`、`/mix_tags`、`/stats`、`/count`、`/order`、`/trades`、
  `/locks`、`/whitelist`、`/blacklist`、`/logs`、`/health`、`/show_config`、`/help`、`/version`、
  `/marketdir`、`/list_custom_data`、`/tg_info` 等全部聊天输出；RPC 层在聊天里回报的错误文案
  （`no active trade`、`trader is not running`、`Maximum number of trades is reached.` 等）同样本地化。
- **语言集与 WebUI 一致**：`en`、`zh-CN`、`zh-TW`、`de`、`ja`、`fr`、`ko`。英文为源语言，某个
  语言缺少条目时自动回退英文，未知 key 不会中断机器人。
- **配置**：`telegram.language`（默认 `en`，取值受 config schema 枚举约束）。
- **运行中切换**：`/language`（别名 `/lang`）无参数时列出全部语言并标记当前项，带参数切换本会话语言；
  选择持久化在 `user_data/bot_languages.json`，重启后仍生效。
- **数据不翻译**：交易对名、`enter_tag`、`exit_reason`、方向/持仓模式取值、交易所返回的状态文本
  原样输出，只有文案本地化。
- **兼容性**：语言为 `en` 时输出与上一版**逐字节一致**（上游 Telegram 测试 110 项不变），旧配置
  无需改动即可升级。
- **实现**：新增 `freqtrade/rpc/i18n.py` 与 `freqtrade/rpc/locales/<area>.<locale>.json`（按区域
  分片，`tg` = Telegram 文案、`rpc` = 聊天可见报错）；新增测试 `tests/rpc/test_i18n.py`
  （语言包完整性 + 占位符一致性闸门）、`tests/rpc/test_telegram_i18n.py`（真实渲染、切换、持久化）。

```
docker pull ericchenghz/ck-quant:2026.9.3-freqai-rl    # FreqAI-RL 变体（同时打 stable-freqai-rl / latest-freqai-rl）
```

数据库、回测结果或模型数据。
