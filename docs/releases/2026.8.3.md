# CK Quant 2026.8.3

这是 CK Quant 手机交易页面的布局修复版本。

## 修复

- 恢复手机端“交易”页面中的图表、未平仓交易和已平仓交易卡片。
- 手机端交易卡片改为按“综合信息、图表、未平仓交易、已平仓交易、交易详情”的顺序单列排列。
- 修正图表卡片错误依赖“交易详情”高度的显示判断。
- 新增移动交易布局回归测试，验证主要卡片可见且互不重叠。

## Android APK

本 Release 附带 `CK-Quant-Android-0.1.3-debug.apk`，版本号为 `0.1.3`，versionCode 为 `4`。

Release 页面会同时公布自动构建 APK 的 SHA-256 校验值。
