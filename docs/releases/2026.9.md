## 上游带来的行为变化

1. **资金费口径修正**：`perf: improved funding fee calculation for backtest`、
   `fix: don't overwrite an order's funding fee when reprocessed`、`fix: don't drop funding-fee candle in data-download`。
   ⇒ 合约回测的**费用口径变了**，跨版本比较费用数字没有意义，旧结论需在同版本内重跑 A/B。
2. **订单/持仓正确性修复**：`check contracts to verify for position openness`（`wallets.py` 改按 `contracts` 判断持仓是否开着）、
   `improved behavior for cross margin`、`ensure fee is never None`、`set pricing_side alongside order_type`、
   `consider existing trade-amount for entry cancels`、`exclude orders with open exit orders`、
   `proactively protect from session errors on shutdown`。
3. **K 线刷新修复一批**：`grace_period` 截断为半根 K 线、`max-poll time` 防止拉到过旧的长周期 K 线、
   `always drop last candle for historic parallel download`、多处 refresh-logic 边界修复 —— 影响信号新鲜度与重复 K 线。
4. **新功能**：`open_interest` K 线类型（并新增"请求了交易所不支持的 candle type 就启动失败"的保护）；
   Telegram 强平预警（新 `LIQUIDATION_WARNING` 消息类型，`liquidation_warn_ratio` 默认 0.2、`liquidation_buffer` 默认 0.05）；
   API 层拒绝 `策略名:base64` 形式的策略名（安全加固）；`show_config` 增加 `proxy_coin`；自定义数据支持 `DELETE`。
5. **binance 杠杆档位表**：877 → 907 个合约（+30 新币、0 删除），其中 12 个合约 `maxLeverage` 变化（11 降 1 升）。
   **已核实：本仓实盘精选名单全部不受影响**，且该文件与上游 2026.9 逐字节一致。
6. **FreqAI/RL 环境**（`Base3/4/5ActionRLEnv`、`BaseEnvironment` 共 29 行）：逐行核对为等价重构，无行为变化。
