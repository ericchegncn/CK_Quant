# CK Quant 2026.9.1

在 `2026.9`（上游 freqtrade 同步）基础上的一次功能发布。

## 新增：游客展示页（公开只读）

- 新增公开端点 `GET /api/v1/public/overview`：**无需登录、只读、默认关闭**（未开启时返回 `404`），
  用于对外展示机器人的运行概况与业绩表现。
- 首屏与登录后的仪表盘一致：机器人概览、累计利润曲线（已实现口径 + 持仓投影线）、
  两张收益率卡与指标网格；单卡片内左右两列，桌面铺满、移动端自动单列。
- **只暴露聚合数字**：不含交易对、策略名、逐笔交易、配置与密钥；服务端聚合后下发，
  带 TTL 缓存，公开链接的重复访问不会穿透到数据库。
- 路由收敛：未登录时访问任意工作区路径都会落到展示页，仅 `/showcase` 与 `/login` 可达；
  未登录不渲染顶栏/底栏，也不发起鉴权请求。
- 设置页新增「游客可见」开关与分享链接，可随时开关对游客的展示。

## 变更

- 累计利润曲线改为与仪表盘同一数据源（已实现利润的累计），持仓浮盈作为**独立投影系列**给出，
  不再混入主线——避免已平仓亏损时曲线被浮盈拉成"盈利"形态。
