# CK Quant 2026.8.2

这是 CK Quant 交易工作区的多语言完整性更新。

## WebUI

- 交易页、仪表盘和图表页的卡片标题、字段、图例、筛选器、空状态及提示文字支持七种语言。
- 强制开仓、强制平仓、启动、停止、暂停和重新加载等交易操作与确认弹窗支持多语言。
- 图表配置、指标设置、模板映射、持仓时长和市场变化等图表内容支持多语言。
- 简体中文、繁体中文、英语、德语、日语、法语和韩语拥有完整且结构一致的交易工作区字典。
- 新增回归测试，验证七种语言的字段结构和动态变量占位符。

## Android APK

本 Release 附带 `CK-Quant-Android-0.1.2-debug.apk`，包含相同的完整多语言界面，
继续使用 CK Quant 品牌图标。APK 为测试签名版本，Android 可能要求允许从当前来源安装。

SHA-256：`9AA8E33FB6E74775330B8D3ACB363A7290994DBF1C276B495206FE2942994FC7`

服务器管理功能仍需在实际加载的配置文件顶层启用：

```json
"ck_quant_admin": {
  "enabled": true,
  "config_edit": true,
  "strategy_edit": true
}
```

远程访问请使用 HTTPS 反向代理或可信 VPN，不要将管理端口直接暴露到公网。
