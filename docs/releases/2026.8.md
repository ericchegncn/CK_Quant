# CK Quant 2026.8

CK Quant 2026.8 brings multilingual administration and mobile access to the
privacy-first Freqtrade distribution.

## 主要更新

- WebUI 新增简体中文、繁体中文、英语、德语、日语、法语和韩语七种界面语言。
- 新增经鉴权保护的管理员工作区，支持配置与策略在线编辑、服务端校验、
  自动备份、变更审计，以及保存后的安全重载。
- 新增 CK Quant Android App，可登录自己的量化服务器，在手机上管理机器人、
  配置、策略、订单和持仓。
- 增强登录、服务器切换和移动端布局，并使用 Android 安全存储保存登录信息。
- Docker Compose 增加管理员功能开关，同时维持配置、策略、数据库和凭据均在
  本地 `user_data` 挂载中的隐私边界。

## Android APK

本 Release 附带 `CK-Quant-Android-0.1.0-debug.apk`，用于本次功能测试。
这是 debug 签名构建，Android 可能提示需要允许从当前来源安装应用。

SHA-256：`A9A6CDBB0B46F497B87EF2DD72EE95249F18C5D56E2C306A17FE15694786E1DF`

安装后输入 CK Quant 服务器地址，以及服务器 `api_server` 中设置的用户名和
密码。建议先连接 `dry_run` 实例。

## 安全提醒

- 管理功能默认关闭，必须通过 `ck_quant_admin` 配置显式启用。
- 请勿将管理端口直接暴露到公网；远程连接应使用 HTTPS 反向代理或可信 VPN。
- 使用高强度独立 API 密码和 JWT 密钥，并妥善保护策略、配置与交易凭据。
- 保存配置或策略前会进行校验，并自动生成备份；操作同时写入审计日志。
