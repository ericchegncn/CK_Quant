# CK Quant 2026.8.4

这是 CK Quant 仪表盘信息架构与收益曲线的统一升级版本。

## 仪表盘

- 将 Bot comparison 与 Cumulative Profit 合并为一张机器人总览卡片。
- 保留原有机器人对比字段，并整合 `/profit` 的收益、交易、胜率、期望值、交易量、利润因子和回撤信息。
- 桌面端采用左右布局，机器人信息在左、收益曲线在右；手机竖屏自动切换为上下布局。
- 收益折线升级为带渐变填充的平滑曲线，并恢复清晰的纵轴高度与网格层次。
- 扩大收益曲线区域和关键统计卡片字号，提高桌面端与手机端可读性。
- 新增和补全七种语言的仪表盘字段翻译。

## 手机交易页面

- 包含 2026.8.3 的移动端布局修复：图表、未平仓交易和已平仓交易卡片均正常显示。
- 增加布局回归测试，避免主要交易卡片再次消失或重叠。

## Android APK

本 Release 附带 `CK-Quant-Android-0.1.4-debug.apk`，版本号为 `0.1.4`，versionCode 为 `5`。

Release 页面同时提供 APK 的 SHA-256 校验文件。
