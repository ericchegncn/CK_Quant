4. 下载Docker镜像
	docker compose pull

5. 创建用户目录结构
	docker compose run --rm freqtrade create-userdir --userdir user_data

6. 创建config.json配置 - 需要回答交互式问题
	要先配置好config.json配置文件，特别是web服务器地址、用户名、密码，以及true

	docker compose run --rm freqtrade new-config --config user_data/config.json

7. 运行FraqAI
	docker compose run freqtrade trade --strategy FreqaiExampleStrategy --config user_data/config_freqai.example.json --freqaimodel PyTorchTransformerRegressor
